# Level 11 → Level 12

`data.txt` is ROT13 this time — every letter shifted 13 places through the alphabet. Level description tells you this outright.

## What I did

`tr` can do character-by-character substitution, so I gave it the normal alphabet and the rotated alphabet:

```bash
cat data.txt | tr 'A-Za-z' 'N-ZA-Mn-za-m'
```

Rotating by 13 twice gets you back to the original, which is why ROT13 is its own inverse — same command works for encoding or decoding.
