# Level 4 → Level 5

`inhere` has a bunch of files this time, only one of which is actually readable text — the rest are junk/binary to throw you off.

## What I did

```bash
cd inhere
ls
```

Gave me a list of files like `-file00`, `-file01`, etc. Instead of catting each one by hand I used `file` to check what type each one actually is:

```bash
file ./-file*
```

Most came back as "data", but one of them said "ASCII text". Catted just that one:

```bash
cat ./-file07
```

(the actual number will vary depending on your instance)
