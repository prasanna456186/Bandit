# Level 1 → Level 2

This one had a file just called `-`, which trips you up if you don't know the trick.

## What I did

`ls` showed a single file named `-`. Tried the obvious thing first:

```bash
cat -
```

That just hangs waiting for terminal input because `-` on its own means "read from stdin" to `cat`. Had to either give it a path or escape the dash:

```bash
cat ./-
```

Using `./` in front tells cat it's a file in the current directory, not an option flag. That printed the password.
