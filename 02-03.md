# Level 2 → Level 3

Filename this time has spaces in it, which also breaks the naive `cat filename` approach.

## What I did

```bash
ls
```

showed something like `spaces in this filename`. If you try to cat that directly the shell splits it into multiple arguments and it fails. Two ways around it — wrap it in quotes, or escape each space:

```bash
cat "spaces in this filename"
```

Got the password from that.
