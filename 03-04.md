# Level 3 → Level 4

Password's in a hidden file inside a subfolder this time.

## What I did

```bash
cd inhere
ls
```

`ls` on its own showed nothing, which usually means the file is hidden (starts with a dot). Added `-a`:

```bash
ls -a
```

That showed `...Hiding-From-You` in there. Catted it:

```bash
cat ...Hiding-From-You
```
