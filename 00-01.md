# Level 0 → Level 1

First level is basically just to check you can log in at all.

## What I did

Connected with:

```bash
ssh bandit0@bandit.labs.overthewire.org -p 2220
```

Password for bandit0 is just `bandit0`, it's given on the Bandit site.

Once I was in I ran `ls` and there was a file called `readme` sitting right there. Read it with:

```bash
cat readme
```

That printed out the password for the next level.
