# Level 14 → Level 15

Shortest one of the bunch. This level just wants the current password (bandit14's) submitted to a specific port on localhost, and it hands back the password for bandit15.

## What I did

Already had bandit14's password from the previous level (`aaWecNkG4FhxJQxz07uiwzVP6bJiYS65`). The level description says to connect to port 30000 on localhost and submit that password.

Used `nc` (netcat) for this, piping the password in:

```bash
echo aaWecNkG4FhxJQxz07uiwzVP6bJiYS65 | nc localhost 30000
```

That connected to the port, sent the password, and the response back was the password for bandit15.
