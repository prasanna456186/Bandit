# Level 5 → Level 6

Now the file we want is buried somewhere in a directory tree (`inhere`), and we're told three things about it: it's 1033 bytes, not executable, and human-readable.

## What I did

`ls -R inhere` showed a bunch of nested folders each with a handful of files, way too many to check by hand. This is where `find` actually earns its keep — you can filter directly on the properties the level description gives you:

```bash
find inhere -size 1033c -not -executable -type f
```

- `-size 1033c` → exactly 1033 bytes (the `c` means bytes)
- `-not -executable` → skip anything with the execute bit set
- `-type f` → only regular files, not directories

That narrowed it down to one file. Catted it and got the password.
